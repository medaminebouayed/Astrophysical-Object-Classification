## ✨ Features

### 🎯 Core Capabilities
- **Multi-class Classification:** Distinguishes between Stars, Galaxies, and Quasars (QSOs)  
- **High Accuracy:** Achieves >95% accuracy on synthetic SDSS-like data  
- **Realistic Simulations:** Generates astrophysically plausible data with proper distributions  
- **Feature Engineering:** Advanced domain-specific feature extraction  

### 🔬 Technical Features
- **Advanced ML Pipeline:** Complete end-to-end machine learning workflow  
- **Hyperparameter Optimization:** Bayesian optimization with Optuna  
- **Ensemble Methods:** Stacking ensemble with multiple base learners  
- **Model Interpretability:** SHAP analysis for feature importance  
- **Interactive Visualizations:** 3D plots, confusion matrices, probability distributions
